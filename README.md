# PWA App Agrorobles (ASMI)

Repositorio de archivos estáticos (Manifiesto de Aplicación Web Progresiva e Iconos) para el sistema de **Mantenimiento y Bitácora de Agrorobles**.

## Contenido del Repositorio
* `manifest.json`: Configuración de la PWA (nombre, tema, orientación y enlace ejecutable).
* `icon-512.png`: Logotipo oficial del sistema ASMI para la pantalla de inicio en dispositivos móviles.

## Despliegue
Alojado públicamente a través de **GitHub Pages**.
